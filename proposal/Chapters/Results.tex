Benchmarks were run using Google's C++ microbenchmarking library \cite{google_benchmark}. This library dynamically runs a warm-up for each benchmark, then runs the benchmark itself repeatedly until the benchmark results reach statistical stability. 

The \texttt{pc2l::Vector} is the core data structure of PC2L. In fact, all of the other data structures are implemented using the vector as a sub-component. As a result, benchmarks were focused around measuring the performance of the vector with the expectation that these results would extend to any data 
structures that can be created with it. Figure \ref{fig:vector_benchmarks_scalability} demonstrates how the performance of various operations on the \texttt{pc2l::Vector} change with different inputs. Each individual graph represents a series of runs for a fixed benchmark on a fixed number of MPI processes. The x-axis of each graph is the number of elements in a \texttt{pc2l::Vector}, and the y-axis is the wall-time (in milliseconds) that was reported by Google Benchmark.
